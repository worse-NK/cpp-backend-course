# C++ и backend-разработка

Учебник для читателей с базовыми знаниями C/C++: от классов и владения ресурсами
до многопоточности, сетей, SQL, серверных API и эксплуатации сервиса.
Внутри — теория, разобранные задачи, тесты и интерактивные лаборатории.

**[Читать онлайн](https://worse-nk.github.io/cpp-backend-course/roadmap/cpp_backend_roadmap.html)**
· **[Скачать готовые сборки](https://github.com/worse-NK/cpp-backend-course/releases/latest)**
· **[Инструкция по сборке](https://github.com/worse-NK/cpp-backend-course/blob/main/docs/BUILDING.md)**

## Как пользоваться

| Вариант | Что нужно | Как открыть |
| --- | --- | --- |
| Сайт | Браузер и интернет | Перейти по ссылке «Читать онлайн» |
| Локальный курс | Браузер и Python 3.10+ | Собрать и запустить командой ниже; дальше чтение работает без интернета |
| Приложение для Linux | Debian/Ubuntu, x86-64 | Скачать `.deb` из Releases и установить; браузер и Python для чтения не нужны |

Это один учебник, а не три независимо редактируемые копии. Сборщики используют
одни исходные материалы, стили, вопросы и лаборатории. Результаты обучения
принадлежат профилю, в котором открыт курс: сайт, localhost и приложение
автоматически не синхронизируют прогресс между собой.

### Запустить локально из исходников

```sh
git clone https://github.com/worse-NK/cpp-backend-course.git
cd cpp-backend-course
python3 tools/course.py serve
```

Открой **http://127.0.0.1:8000/**. Терминал должен оставаться открытым;
`Ctrl+C` останавливает сервер. Он раздаёт только собранный учебник и слушает
локальный адрес, а не сетевые интерфейсы компьютера. Python-пакеты, npm,
Docker и компилятор для этого не нужны.

Готовый `cpp-backend-course-local_ВЕРСИЯ.zip` из Releases — другой способ
получить тот же локальный курс без клонирования. Внутри архива есть своя
инструкция запуска. Веб-архив и локальный архив не следует путать: локальный
содержит также закреплённые копии библиотек и шрифтов.

### Установить приложение

Скачай `.deb` из [Releases](https://github.com/worse-NK/cpp-backend-course/releases/latest).
Например, для версии 1.1.1 из папки с загруженным файлом:

```sh
sudo apt install ./cpp-backend-course-desktop_1.1.1_amd64.deb
cpp-backend-course-desktop
```

Установщик включает собственный Electron — движок, который показывает учебник
в отдельном окне. Главы и встроенные лаборатории доступны без интернета с первого
запуска. Компиляторы, базы данных, Docker и другие инструменты серверных
практикумов в установщик не входят. Интернет также нужен для внешних статей.

## Что лежит в репозитории

```text
roadmap/                 готовая веб-версия и исходники учебника
  content/               теория, задания, определения терминов
  assets/                интерфейс, стили и интерактивные лаборатории
  examples/              скачиваемые учебные проекты
  tools/                 сборщики и проверки курса
desktop-course/          исходники приложения и сборщика .deb
  app/                   Electron: окно, протокол, безопасность
  vendor/                закреплённые библиотеки, шрифты и их лицензии
  icons/                 исходный SVG и готовые значки
tools/                   общие команды запуска, сборки и выпуска
docs/                    инструкции для читателя и разработчика
.github/workflows/       сборка готовых выпусков в GitHub Actions
```

Папка `roadmap/` и адреса существующих страниц сохранены. Исходные данные
редактируют в `roadmap/content/`, а не в сгенерированных файлах `roadmap/generated/`.

## Редактирование и сборка

Команды выполняются из корня клона. Первая сборка `.deb` скачивает проверенный
Electron; остальные команды сборки не устанавливают системные программы.

```sh
python3 tools/course.py web       # сайт и веб-архив в publish/
python3 tools/course.py local     # автономная браузерная сборка в build/local/
python3 tools/course.py desktop   # содержимое приложения, пока без движка
python3 tools/course.py deb       # полный .deb, Linux amd64
python3 tools/course.py check     # быстрые проверки сборщиков
```

Для `.deb` нужен `dpkg-deb`; готовый пакет не перезаписывается молча.
Подробности, дополнительные параметры и ограничения:
[BUILDING.md](https://github.com/worse-NK/cpp-backend-course/blob/main/docs/BUILDING.md).

Git хранит исходники, но не результаты каждой сборки. В `git clone` не входят
готовые `.deb` из Releases, загруженный Electron, кэши и чей-либо прогресс.
Пакет можно отдельно скачать или собрать указанной командой.

## Выпуски и безопасность

- [Как устроен выпуск](https://github.com/worse-NK/cpp-backend-course/blob/main/docs/RELEASING.md): тег, сборка, контрольные суммы и готовые архивы.
- [Защита простыми словами](https://github.com/worse-NK/cpp-backend-course/blob/main/docs/SECURITY.md): внешние библиотеки, CSP, проверка секретов и её границы.
- [Сторонние компоненты](https://github.com/worse-NK/cpp-backend-course/blob/main/docs/THIRD_PARTY.md): версии и сохранённые лицензии.

Не коммить реальные `.env`, ключи, пользовательские профили и резервные копии.
Учебные секреты создаются читателем в своей локальной среде; заглушки из примеров
не предназначены для рабочих сервисов. Открытие учебника не запускает команды
серверных практикумов.
