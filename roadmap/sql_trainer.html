СТАНЦИЯ 9A · ПРАКТИКА В БРАУЗЕРЕ

Напиши запрос. Посмотри на данные.

В этом тренажёре есть вымышленные люди и их список дел: у Анны две задачи, у Бориса одна, а у Веры пока ни одной. Попробуем узнать, кому что осталось сделать, посчитать задачи и изменить одну запись, не затронув остальные. Так станет понятно, как программа получает нужную информацию из сохранённых данных.

Данные разложены по двум таблицам — спискам со строками и именованными столбцами. В users одна строка описывает человека: его номер id и имя name. В tasks одна строка — задача: номер id, номер её владельца owner_id, название title, отметка выполнения done и необязательный приоритет priority. Например, owner_id = 1 связывает задачу с Анной, а не с задачей № 1. Все исходные записи можно раскрыть ниже.

SQL — язык команд для работы с такими таблицами. Выбери упражнение в списке: сначала будет простое вычисление без таблиц, затем чтение и изменение списка дел. Прочитай условие, введи команду в поле «Твой SQL» и нажми «Выполнить», чтобы увидеть результат, или «Проверить решение», чтобы сверить его с заданием. Подсказка и разбор открываются отдельно.

Здесь работает SQLite — встроенный в страницу механизм выполнения SQL, а не сервер PostgreSQL. Каждый запуск получает свежую копию исходных таблиц; реальные данные и серверы не затрагиваются. Проверка использует также второй подготовленный набор записей: решение должно выражать правило, а не перечислять запомненные номера.

Исходные таблицы и схема

В основном наборе Анна — пользователь 1: её задача 10 «Написать тест» ещё не выполнена, а задача 11 «Обновить README» уже выполнена. Борис — пользователь 2, ему принадлежит незавершённая задача 12 «Проверить API». Вера — пользователь 3, на неё пока не ссылается ни одна задача.

done = 0 означает «не выполнено», done = 1 — «выполнено». priority принимает числа от 1 до 5; NULL означает, что приоритет не задан, а не равен нулю. Ниже записана схема — команды создания таблиц и исходных записей. В PostgreSQL boolean — отдельный тип; SQLite также иначе проверяет типы и некоторые кавычки. Успех здесь не доказывает переносимость всего синтаксиса.




Можно написать несколько команд через «;». Изменения живут только в рамках одного запуска. Черновик запроса сохраняется в этом браузере, если доступно локальное хранилище.
