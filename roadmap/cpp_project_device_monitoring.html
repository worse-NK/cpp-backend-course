ИТОГОВЫЙ ПРИМЕР 0–3

Система мониторинга устройств

Один цельный учебный проект, который связывает базу ООП, современный C++ и полиморфизм: устройства, общий интерфейс, реестр-владелец, опрос, поиск, сброс и статистика.

Техническое задание

Написать консольную программу на C++20, моделирующую систему мониторинга набора устройств. В системе должны быть разные типы устройств, но общий код должен работать с ними единообразно через интерфейс.

  • Есть показание Reading: числовое значение + единица измерения.
  • Есть абстрактный интерфейс Device: имя, чтение, сброс.
  • Есть минимум три реализации: температурный датчик, датчик напряжения, реле.
  • Есть DeviceRegistry, который владеет устройствами через std::unique_ptr.
  • Реестр умеет добавить устройство, опросить всех, найти и прочитать по имени, сбросить одно устройство или все сразу.
  • Реестр умеет считать статистику min/max/average/count по отфильтрованным показаниям.
  • В финальном коде нет ручных new/delete.

Что покрывает

Станция 0

Классы, private-поля, конструкторы, const-геттеры, инкапсуляция данных.

Станция 1

RAII (освобождение ресурса деструктором владельца), unique_ptr, vector, move и явная передача владения.

Станция 2

Абстрактный класс, virtual/override, виртуальный деструктор, полиморфный вызов.

Станция 3

optional, предикат (функция проверки условия), лямбды и вычисления по единому снимку показаний (snapshot).

Как запустить

Сохрани код ниже в main.cpp и запусти команду:

g++ -std=c++20 -Wall -Wextra -pedantic -o main main.cpp && ./main

Основная версия языка для готового маршрута — C++20; предупреждения компилятора включены намеренно.

Полный код

#include <cstddef>
#include <cstdlib>
#include <iostream>
#include <memory>
#include <optional>
#include <stdexcept>
#include <string>
#include <string_view>
#include <utility>
#include <vector>

class Reading {
    std::string unit_;
    double value_;
public:
    Reading(std::string unit, double value)
        : unit_(std::move(unit)), value_(value) {}

    const std::string& getUnit() const { return unit_; }
    double getValue() const { return value_; }
};

struct NamedReading {
    std::string deviceName;
    Reading reading;
};

struct Stats {
    double min;
    double max;
    double average;
    std::size_t count;
};

class Device {
public:
    virtual ~Device() = default;
    virtual const std::string& getName() const = 0;
    virtual Reading read() = 0;
    virtual void reset() = 0;
};

class DeviceRegistry {
    std::vector<std::unique_ptr<Device>> devices_;

    Device* findByName(std::string_view name) const {
        for (const auto& device : devices_) {
            if (device->getName() == name)
                return device.get();  // невладеющий указатель
        }
        return nullptr;
    }

public:
    void add(std::unique_ptr<Device> device) {
        if (!device)
            throw std::invalid_argument("device must not be null");
        if (device->getName().empty())
            throw std::invalid_argument("device name must not be empty");
        if (findByName(device->getName()))
            throw std::invalid_argument("duplicate device name: " + device->getName());
        devices_.push_back(std::move(device));
    }

    std::size_t size() const { return devices_.size(); }

    std::vector<NamedReading> collectSnapshot() {
        std::vector<NamedReading> result;
        result.reserve(devices_.size());
        for (const auto& device : devices_)
            result.push_back({device->getName(), device->read()});
        return result;
    }

    static void printSnapshot(const std::vector<NamedReading>& snapshot) {
        for (const auto& item : snapshot) {
            std::cout << "Device: " << item.deviceName
                      << ", Reading: " << item.reading.getValue()
                      << ' ' << item.reading.getUnit() << '\n';
        }
    }

    static std::optional<Reading> readByName(
            const std::vector<NamedReading>& snapshot,
            std::string_view name) {
        for (const auto& item : snapshot) {
            if (item.deviceName == name)
                return item.reading;
        }
        return std::nullopt;
    }

    template<class Predicate>
    static std::optional<Stats> statsWhere(
            const std::vector<NamedReading>& snapshot,
            Predicate predicate) {
        std::optional<Stats> stats;
        double sum = 0.0;

        for (const auto& item : snapshot) {
            if (!predicate(item.reading))
                continue;

            const double value = item.reading.getValue();
            if (!stats) {
                stats = Stats{value, value, 0.0, 0};
            } else {
                if (value < stats->min) stats->min = value;
                if (value > stats->max) stats->max = value;
            }
            sum += value;
            ++stats->count;
        }

        if (stats)
            stats->average = sum / static_cast<double>(stats->count);
        return stats;
    }

    bool resetByName(std::string_view name) {
        if (Device* device = findByName(name)) {
            device->reset();
            return true;
        }
        return false;
    }

    void resetAll() {
        for (const auto& device : devices_)
            device->reset();
    }
};

class TemperatureSensor final : public Device {
    std::string name_;
    double initial_;
    double last_;
public:
    TemperatureSensor(std::string name, double initial)
        : name_(std::move(name)), initial_(initial), last_(initial) {}

    const std::string& getName() const override { return name_; }

    Reading read() override {
        last_ += static_cast<double>(std::rand()) / RAND_MAX * 1.5;
        return Reading("°C", last_);
    }

    void reset() override { last_ = initial_; }
};

class VoltageSensor final : public Device {
    std::string name_;
    double initial_;
    double last_;
public:
    VoltageSensor(std::string name, double initial)
        : name_(std::move(name)), initial_(initial), last_(initial) {}

    const std::string& getName() const override { return name_; }

    Reading read() override {
        last_ += static_cast<double>(std::rand()) / RAND_MAX * 3.0;
        return Reading("V", last_);
    }

    void reset() override { last_ = initial_; }
};

class Relay final : public Device {
    std::string name_;
    bool isOn_ = false;
public:
    explicit Relay(std::string name) : name_(std::move(name)) {}

    const std::string& getName() const override { return name_; }
    Reading read() override { return Reading("state", isOn_ ? 1.0 : 0.0); }
    void reset() override { isOn_ = false; }
};

void printStats(std::string_view label, const std::optional<Stats>& stats) {
    if (!stats) {
        std::cout << label << ": no readings\n";
        return;
    }
    std::cout << label << ": min=" << stats->min
              << ", max=" << stats->max
              << ", avg=" << stats->average
              << ", count=" << stats->count << '\n';
}

int main() {
    DeviceRegistry registry;
    registry.add(std::make_unique<TemperatureSensor>("Temperature 1", 24.0));
    registry.add(std::make_unique<TemperatureSensor>("Temperature 2", 27.0));
    registry.add(std::make_unique<Relay>("Relay 1"));
    registry.add(std::make_unique<VoltageSensor>("Voltage 1", 218.0));
    registry.add(std::make_unique<VoltageSensor>("Voltage 2", 231.0));

    const auto snapshot = registry.collectSnapshot(); // каждый Device::read() ровно один раз
    DeviceRegistry::printSnapshot(snapshot);

    printStats("temperature", DeviceRegistry::statsWhere(snapshot,
        [](const Reading& reading) { return reading.getUnit() == "°C"; }));
    printStats("voltage", DeviceRegistry::statsWhere(snapshot,
        [](const Reading& reading) { return reading.getUnit() == "V"; }));

    if (auto relay = DeviceRegistry::readByName(snapshot, "Relay 1"))
        std::cout << "Relay 1 in snapshot: " << relay->getValue() << '\n';

    registry.resetAll();
}

Разбор архитектуры

1. Reading: отдельный тип для результата измерения

Reading нужен, чтобы не возвращать просто double. Число без единицы измерения теряет смысл: 25.0 может быть температурой, напряжением или состоянием реле. Поэтому показание хранит и значение, и строку единицы.

Поля закрыты в private, наружу данные выдаются через const-геттеры. getUnit() возвращает const std::string&, чтобы не копировать строку и не разрешать внешнему коду менять внутреннее поле.

2. Device: общий контракт

Device — это абстрактный интерфейс. Он не хранит конкретных данных датчика, а только требует, чтобы каждое устройство умело вернуть имя, снять показание и сброситься.

= 0 делает методы чисто виртуальными, поэтому объект Device создать нельзя. Это правильно: абстрактного “просто устройства” в программе нет, есть конкретные устройства.

В нашем проекте unique_ptr<Device> удаляет производные объекты через указатель на базовый класс. Поэтому деструктор Device должен быть виртуальным: так сначала разрушится производный объект, затем его базовая часть. Без этого такое удаление в C++20 — неопределённое поведение (стандарт не задаёт результат), а не просто пропуск одного вызова. Само наличие виртуальных методов не требует виртуального деструктора, если удаление через базу запрещено, например защищённым невиртуальным деструктором.

3. Конкретные устройства

TemperatureSensor, VoltageSensor и Relay наследуются от Device и реализуют один и тот же интерфейс по-разному.

  • Температурный датчик возвращает °C.
  • Датчик напряжения возвращает V.
  • Реле возвращает state и значение 0 или 1.

Ключевое слово override просит компилятор проверить, что метод действительно переопределяет виртуальный метод базы. Это защита от тихих ошибок в сигнатуре.

4. DeviceRegistry: владелец устройств

DeviceRegistry хранит std::vector<std::unique_ptr<Device>>. Это значит: реестр владеет устройствами, а устройства могут быть разных реальных типов.

unique_ptr нельзя копировать, поэтому метод add() принимает владение и перемещает указатель через std::move. После этого устройство живёт внутри реестра и удалится автоматически при уничтожении реестра.

Главная архитектурная победа: pollAll() не знает, какие именно устройства лежат внутри. Он вызывает device->read(), а C++ сам выбирает нужную реализацию по реальному типу объекта.

5. optional: когда результата может не быть

readByName() ищет устройство по имени. Если устройство найдено, возвращается Reading. Если не найдено, возвращается std::nullopt.

Это честнее, чем возвращать фиктивное значение. Отсутствие устройства — нормальная ситуация, и std::optional<Reading> явно выражает это в типе результата.

6. Шаблонный предикат и snapshot

statsWhere() — шаблон: конкретный тип переданной функции сохраняется при компиляции. Функция служит предикатом — возвращает true для показаний, которые надо учитывать. В main() это лямбды для °C и V. Оборачивать их в std::function не требуется: эта обёртка использует стирание типа (type erasure — единый интерфейс вызова, скрывающий конкретный тип функции), а здесь такой общий тип нам не нужен.

Сначала collectSnapshot() вызывает каждое устройство ровно один раз. Печать, поиск и обе статистики используют один и тот же неизменяемый снимок, поэтому сравнивают согласованные показания.

7. Почему main стал коротким

main() больше не управляет памятью, не хранит сырые указатели и не знает, как опрашивать каждый тип устройства отдельно. Он собирает систему: создаёт реестр, добавляет устройства и запускает сценарии.

Это ближе к промышленному стилю: конкретные классы отвечают за своё поведение, реестр отвечает за хранение и оркестрацию, а main() остаётся точкой сборки приложения.

Что важно заметить

  • Добавление нового устройства требует нового класса, но не требует менять DeviceRegistry::pollAll().
  • Владение объектами выражено через типы: unique_ptr владеет, сырой указатель из .get() только наблюдает.
  • Полиморфизм работает через указатель или ссылку на базовый класс: здесь это unique_ptr<Device>.
  • collectSnapshot() отделяет ввод-вывод от анализа: каждое устройство читается один раз, затем все отчёты строятся по согласованным данным.
  • add() отвергает null, пустое имя и дубликаты до помещения устройства в реестр.
