# Запуск и сборка

Сначала выбери, что нужно получить. Для чтения курса компилировать C++ не нужно:
страницы и встроенные задания работают в браузере или Electron. Компилятор и
серверные инструменты понадобятся, когда начнёшь выполнять соответствующую практику.

## Подготовка исходников

```sh
git clone https://github.com/worse-NK/cpp-backend-course.git
cd cpp-backend-course
python3 tools/course.py --help
```

Для основных сборщиков нужен Python 3.10 или новее со стандартной библиотекой.
Устанавливать npm-пакеты или зависимости через pip для сборки курса не требуется.
Готовые значки уже лежат в Git: их необязательно перерисовывать при сборке.

## Локальный браузерный курс

```sh
python3 tools/course.py serve
```

Команда собирает `build/local/` и запускает локальный сервер.
Открой `http://127.0.0.1:8000/` в своём браузере. React, SQLite/sql.js,
подсветка и используемые шрифты берутся из локальных файлов. Для чтения этой
сборки интернет не нужен; ссылки на внешние статьи и получение инструментов
для практики остаются сетевыми действиями.

Сервер слушает только `127.0.0.1`: команда не публикует курс в локальную сеть
или интернет. Раздаётся собранный набор, а не исходный репозиторий с `.git`.
Сервер ничего не выполняет из учебных проектов. Чтобы остановить его, нажми `Ctrl+C`.

Если порт занят:

```sh
python3 tools/course.py serve --port 8001
```

Адрес включает порт, поэтому `127.0.0.1:8000` и `127.0.0.1:8001` имеют раздельное
браузерное хранилище. Для продолжения обучения лучше пользоваться одним адресом
и профилем браузера. Очистка данных браузера и режим инкогнито могут удалить прогресс.

Если нужен только результат, без запуска сервера:

```sh
python3 tools/course.py local
```

По умолчанию получатся папка `build/local/` и архив
`build/cpp-backend-course-local.zip`. Можно передать готовый архив другому
человеку; для его чтения не нужны Git и исходники сборщиков. Инструкция запуска
лежит внутри. Автоматическая установка PWA и service worker не используются.

## Веб-версия

```sh
python3 tools/course.py web
```

Результат: `publish/github-pages/` и `publish/cpp-backend-course.zip`.
Это раздача готового сайта без исходных JSON, инфраструктуры тестов и
desktop-приложения. Для собственного хостинга используют содержимое папки
`publish/github-pages/`; существующие адреса `roadmap/...` сохраняются.

В этой веб-сборке сохранена текущая доставка React с unpkg и шрифтов с Google
Fonts; для шрифтов предусмотрена системная замена. Веб-архив не обещает
полной автономности. Если нужен браузерный вариант без этих зависимостей,
собери `local` или скачай локальный архив из Releases.

Готовые HTML в исходном `roadmap/` тоже можно открыть. Локальный HTTP-запуск
предпочтительнее `file://`: у браузеров различаются ограничения файловых
страниц и поведение их хранилища. Один скопированный HTML без соседних папок
не содержит всего курса.

## Electron и Debian-пакет

Содержимое приложения отдельно от движка:

```sh
python3 tools/course.py desktop
```

Оно появится в `desktop-course/release/site/`. Это ещё не установленная
программа: пакет с движком создаёт следующая команда.

```sh
python3 tools/course.py deb
```

Целевая платформа — Linux x86-64, пакет `amd64` для Debian/Ubuntu.
Нужен `dpkg-deb` из пакета `dpkg`. На Debian/Ubuntu при необходимости:

```sh
sudo apt install python3 git dpkg
```

Сам сборщик запускается **без sudo**. В первый раз он получает официальный
Electron 45.2.3 в `desktop-course/.toolchain/`, сверяет опубликованную сумму
с закреплённой SHA-256, затем проверяет файлы при упаковке. Для первого
получения движка нужен интернет; проверенная локальная копия используется повторно.

Готовый пакет: `desktop-course/release/cpp-backend-course-desktop_1.1.1_amd64.deb`
для текущей версии приложения 1.1.1. Версия берётся из
`desktop-course/app/package.json`, а не угадывается по номеру коммита.
Повторная сборка не должна молча перезаписывать уже выпущенный пакет:
используй другую выходную папку через `deb --output` или повысь версию для нового выпуска.

Установка — отдельное действие:

```sh
sudo apt install ./desktop-course/release/cpp-backend-course-desktop_1.1.1_amd64.deb
cpp-backend-course-desktop
```

`apt` может потребовать интернет, если в системе нет необходимых графических
библиотек. После установки браузер, Python, Node.js и локальный HTTP-сервер
для чтения не нужны. Запускай приложение от обычного пользователя: не отключай
песочницу флагом `--no-sandbox` и не запускай окно через sudo.

Прогресс хранится отдельно от `/opt`, в профиле приложения. Сборка пакета
не читает этот профиль; обновление сохраняет прежнее имя приложения и адрес
`course://app/`. Перед обновлением полезно экспортировать прогресс через меню
приложения. Данные сайта и localhost автоматически в приложение не переносятся.

## Изменение теории и проверки

Теория и вопросы станций — в `roadmap/content/station*.json`, закрепления —
в `roadmap/content/checkpoints/`. Сгенерированные `roadmap/generated/*.js`
не служат исходниками текста. После изменения станции:

```sh
python3 roadmap/tools/build_stations.py --station station0
python3 roadmap/tools/validate_materials.py
python3 tools/course.py check
```

Последняя команда проверяет сборщики и упаковку, но не заменяет приёмку всех
лабораторий или проверку текста по первоисточникам. Тесты C++ требуют подходящего
компилятора и стандартной библиотеки C++20/23; часть JS-проверок использует GJS.
GUI, Docker, PostgreSQL и VM-проверки требуют собственной подготовленной среды.
Их отсутствие не следует выдавать за успешно проверенную практику.

Сборщики отказываются перезаписывать посторонние или вручную изменённые файлы
в выходных папках. При таком сообщении выбери новый `--output`, а не удаляй
папку с личной работой. `publish/`, `build/`, `.toolchain/`, установщики,
пользовательские профили и кэши не предназначены для Git.
