# Сторонние компоненты

Исходники курса используют небольшие сторонние библиотеки. Их копии,
лицензии и сведения о происхождении сохраняются вместе с проектом.

| Компонент | Для чего нужен | Где зафиксирован |
| --- | --- | --- |
| React и ReactDOM 18.3.1 | Интерфейс станций и тестов | `desktop-course/vendor/ORIGIN.json`, лицензии MIT рядом с JS |
| Inter и JetBrains Mono | Шрифты автономных сборок | Тот же `ORIGIN.json`, лицензии SIL OFL 1.1 в `desktop-course/vendor/fonts/` |
| highlight.js | Подсветка кода | `roadmap/vendor/highlightjs/ORIGIN.json`, `LICENSE` BSD 3-Clause |
| sql.js / SQLite | Локальное выполнение SQL-тренажёра | `roadmap/vendor/sqljs/`, лицензия sql.js MIT и README поставки |
| Electron 45.2.3 / Chromium | Движок отдельного приложения | `desktop-course/fetch_runtime.py`, проверяемый архив; лицензии поставляются внутри runtime и `.deb` |

Файлы в `desktop-course/vendor/` проверяются по SHA-256 перед сборкой.
Сам Electron в Git не хранится: сборщик скачивает определённый выпуск с
официального GitHub и проверяет закреплённый хеш архива и карту его файлов.
Это проверка целостности, не отдельная криптографическая подпись автора курса.

В готовом приложении лицензии Electron и Chromium находятся под
`/opt/cpp-backend-course-desktop/`; уведомления библиотек — рядом с локальными
файлами курса. Устанавливаемый пакет также содержит сведения в
`/usr/share/doc/cpp-backend-course-desktop/`.

Факт публичной публикации репозитория сам по себе не задаёт новую лицензию
авторскому тексту и коду курса. Этот файл перечисляет сторонние компоненты;
отдельную лицензию для оригинальных материалов здесь не назначаем.
