Твой курс и прогресс

Учебник уже установлен на компьютере. Здесь можно сохранить свои отметки и результаты в файл, перенести их из прежней версии или восстановить из резервной копии.

Учебник работает локально

Главы, тесты и встроенные лаборатории открываются из файлов приложения — без браузера и без подключения к серверу.

Сохранить прогресс

Отметки изученных разделов, записанные результаты тестов, размер текста и SQL-черновики сохраняются в профиле этого приложения. Закрытие окна и обычное обновление программы не должны их удалять. Резервный файл поможет перенести данные на другой компьютер или восстановить их, если профиль будет повреждён.

Незавершённая попытка теста остаётся только в открытом окне, как и в браузерной версии. Заверши её перед закрытием приложения. Резервная копия содержит только данные курса, не настройки и историю твоего обычного браузера.

Восстановить или перенести данные

Выбери ранее сохранённый JSON-файл (текстовый файл с данными прогресса). Сначала приложение проверит его, затем попросит подтверждение. Перед заменой будет предложено сохранить нынешний прогресс.

Восстановление заменяет одноимённые записи из файла; остальные отметки остаются. Перед ним закрой другие окна курса, чтобы они не записали старое состояние поверх восстановленного. После восстановления открой нужную главу заново.

Как перенести прогресс из сайта или прежней PWA?

У сайта, прежней локальной PWA и нового приложения разные профили. Приложение не читает чужие данные автоматически. Если в прежней версии есть экспорт, сначала сохрани файл там, а затем загрузи его здесь.

Для старых страниц без кнопки экспорта есть закладка. Она читает только ключи этого учебника и скачивает резервный файл: ничего не отправляет в интернет и не меняет отметки.

  1. Перетащи ссылку «Сохранить старый прогресс» на панель закладок своего прежнего браузера. Здесь запускать её не нужно.
  2. В том же профиле браузера открой старый курс на worse-nk.github.io/cpp-backend-course/, прежний HTML-файл станции или локальную PWA на 127.0.0.1:47653. Нажми добавленную закладку и сохрани файл.
  3. Вернись в приложение и выбери этот файл выше.

Если браузер не позволяет перетащить ссылку между приложениями, нажми кнопку ниже и создай в нём закладку вручную, вставив скопированный адрес. Это исполняемый адрес javascript:: используй только подготовленный здесь код. При запрете таких закладок политиками браузера данные не меняются.

Для file:// браузер может хранить прогресс каждой страницы отдельно. Тогда повтори экспорт на нужных станциях и загрузи файлы по очереди. Не удаляй старые данные браузера до проверки переноса.

Что входит в приложение

Все главы, тесты, модели и SQL-тренажёр уже в установочном пакете. Ничего дополнительно скачивать для их открытия не нужно. Программа содержит собственный движок Chromium — часть, которая отображает страницы и выполняет их JavaScript. Поэтому установленный Chrome или Firefox не требуется.

Практикумы с компилятором C++, Docker, Kubernetes, PostgreSQL или анализом настоящего сетевого трафика выполняются отдельно по инструкции. Программа не устанавливает эти инструменты и не запускает команды из примеров. Для внешних статей и загрузки инструментов нужен интернет; внешняя ссылка по твоему выбору откроется в обычном браузере.

Обновление устанавливается новым .deb; постоянное подключение к сети и фоновое автообновление не требуются. Удаление приложения не означает удаление профиля с прогрессом.
